СБОРКА APK ТОЛЬКО С ТЕЛЕФОНА (через GitHub Actions)

1. Войдите или создайте аккаунт на GitHub.
2. В браузере откройте GitHub и создайте новый репозиторий (New repository). Название, например: Granta-Drive. Для простоты можно выбрать Public; не загружайте в репозиторий личные данные.
3. Распакуйте LadaGrantaLauncher_source.zip на телефоне.
4. Откройте созданный репозиторий на GitHub → Add file → Upload files.
5. Загрузите ВСЕ содержимое папки LadaGrantaLauncher, включая скрытую папку .github. В корне репозитория должны быть build.gradle, settings.gradle, gradle.properties, папка app и папка .github.
   Важно: некоторые мобильные файловые менеджеры скрывают папки с точкой. Убедитесь, что .github/workflows/build-apk.yml тоже загружен.
6. Нажмите Commit changes.
7. Откройте вкладку Actions → Build Granta Drive APK. Если сборка не стартовала автоматически, нажмите Run workflow.
8. Дождитесь зелёной галочки. Откройте завершённый запуск и скачайте артефакт Granta-Drive-APK внизу страницы. Это ZIP с app-debug.apk внутри.
9. Распакуйте скачанный ZIP, перенесите app-debug.apk на магнитолу и установите. Если Android спросит, разрешите установку приложений из этого источника.

Если вкладки Actions нет или workflow не запускается, откройте Settings → Actions → General и разрешите действия (Actions). Интерфейс GitHub на телефоне может отличаться.

Примечания:
- APK — отладочная сборка, а не опубликованное приложение.
- Запуск кнопок зависит от наличия соответствующих приложений на магнитоле.
- Погода и данные автомобиля в макете демонстрационные; реальное подключение к машине не реализовано.
