Granta Drive — проект лаунчера для Android-магнитолы

Цель: экран 1280x720, Android 8.1 (API 27 и выше по совместимости).
В проекте есть главный экран с белой LADA Granta 2017, часами, русскими подписями и кнопками запуска карт, музыки, Bluetooth, YouTube и настроек.

ВАЖНО:
- Это исходный проект Android-приложения, а не готовый APK. В этой среде нет Android SDK/Gradle, поэтому скомпилировать и проверить APK здесь не удалось.
- Кнопки открывают соответствующие приложения/разделы, если они установлены на магнитоле. Виджет погоды и показания автомобиля пока демонстрационные; для реальных данных нужны погодный API и подключение к автомобилю/OBD-II.
- Перед сборкой откройте проект в Android Studio, дождитесь синхронизации Gradle и выберите Build > Build APK(s). APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.
- Установка APK: скопируйте файл на магнитолу, откройте файловым менеджером и разрешите установку из неизвестных источников, если Android попросит. Затем запустите Granta Drive и при желании выберите его как приложение «Главный экран».

Требования для сборки: Android Studio с Android SDK 34 и JDK 17.
